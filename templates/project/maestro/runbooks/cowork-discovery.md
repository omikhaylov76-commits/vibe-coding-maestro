# Cowork Discovery

Это runbook. Скопируйте prompt ниже в Cowork.

## Копируемый prompt

Проведи discovery проекта. Cowork не пишет код и не изменяет файлы проекта: результатом должен быть только Markdown-текст для проверки человеком.

Изучи предоставленные материалы, отделяй факты от гипотез и верни Markdown со следующими разделами:

## Sources
Перечисли источники и укажи, какие утверждения подтверждает каждый из них.

## Assumptions
Перечисли непроверенные предположения и способ их проверки.

## MVP
Определи минимальный проверяемый объём продукта и критерии успеха.

## Non-goals
Явно перечисли то, что не входит в MVP.

## Open questions
Собери нерешённые вопросы, владельца ответа и влияние на MVP.

Не выдумывай отсутствующие сведения. Попроси уточнение там, где источник недостаточен.

## Контролируемый импорт результата

Cowork не изменяет файлы проекта. Человек копирует результат в `wiki/concepts/discovery.md`, просматривает полный diff, затем принимает или отклоняет изменение. Claude Code читает discovery, но не переписывает его.
