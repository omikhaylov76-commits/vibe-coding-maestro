# Входящие материалы

Складывайте здесь всё, что пока не разобрано: заметки, ссылки, выгрузки, скриншоты.

Правила:

- один материал — один файл, имя человекочитаемое;
- после разбора переносите суть в `wiki/concepts/` и удаляйте черновик или отправляйте в `wiki/attic/`;
- большие исходники держите в `maestro/sources/`.

Эта папка — буфер, а не архив.
