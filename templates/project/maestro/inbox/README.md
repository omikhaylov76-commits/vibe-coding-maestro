# Входящие материалы

Одно место для ваших материалов: заметки, требования, выгрузки, скриншоты, документы заказчика — любые файлы, любого размера.

Правила:

- кладите файлы как есть: агент их не правит и не удаляет;
- суть, которую подтвердил человек, агент записывает в `wiki/concepts/discovery.md` со ссылкой на файл здесь;
- git хранит эти файлы байт в байт: правило `-text` в `.gitattributes` этой папки не даёт ему менять переносы строк;
- `doctor` не считает файлы здесь замечанием;
- `maestro/sources/` — не для материалов: там только снимки команды `sources`.
