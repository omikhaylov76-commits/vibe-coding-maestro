# Журнал решений и работ

Одна запись — одно завершённое действие. Пишите в конец файла, старое не переписывайте.

Формат заголовка записи (дату подставляйте фактическую):

```
## ГГГГ-ММ-ДД — краткая суть
```

Каждая запись содержит:

- **Что сделано** — факт, а не намерение.
- **Почему** — причина или ссылка на решение в `wiki/decisions/`.
- **Что дальше** — следующий шаг, если он уже понятен.

Записи начнутся после первого выполненного шага.
