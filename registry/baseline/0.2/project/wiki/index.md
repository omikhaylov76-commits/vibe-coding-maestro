# Карта памяти проекта {{PROJECT_NAME}}

Навигация по файловой памяти. Начинайте с `hot.md`.

## Основное

- `hot.md` — горячий контекст текущей сессии.
- `roadmap.md` — этапы и их состояние.
- `log.md` — журнал сделанного.
- `concepts/discovery.md` — что за продукт и для кого.

## Каталоги

- `concepts/` — устойчивые понятия и решения о продукте.
- `progress/` — детальный прогресс по фичам.
- `decisions/` — принятые технические решения.
- `audits/` — результаты проверок.
- `handoffs/` — передача контекста между сессиями.
- `attic/` — устаревшее, но не удаляемое.

## Материалы

- `maestro/inbox/` — входящие материалы на разбор.
- `maestro/sources/` — исходники и выгрузки.
- `maestro/runbooks/` — повторяемые процедуры.
