# Паспорт проекта

Где что живёт и как этим управлять. Файл принадлежит проекту. Ведётся с первого дня: завели ресурс — сразу запись здесь. «Пока нет» значит «ещё не заполнено». Раздел, который не нужен, не удаляйте — напишите «не применимо». Проект без кода (настройка готового сервиса) ведёт паспорт так же.

Значения ключей, паролей и токенов сюда не пишутся никогда — только имена и где они задаются.

Паспорт уходит получателю результата — заказчику, команде, работодателю — в `HANDOVER.md` при упаковке. Пишите его для получателя: так, чтобы человек без доступа к этой переписке понял, где что живёт и что делать.
