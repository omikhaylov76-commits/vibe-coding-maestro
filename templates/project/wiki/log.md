# Журнал решений и работ

Одна запись — одно завершённое действие. Пишите в конец файла, старое не переписывайте.
Журнал больше 20 000 знаков: команда `vibe-maestro archive` переносит старые записи в `wiki/log/ГГГГ-ММ.md`, по файлу на месяц; новые записи всё равно идут сюда.

Формат заголовка записи (дату подставляйте фактическую):

```
## ГГГГ-ММ-ДД — краткая суть
```

Каждая запись содержит:

- **Что сделано** — факт, а не намерение, одной строкой.
- **Ссылка на передачу** — «почему» и «что дальше» записаны в ней. Передачи нет — допишите их здесь.

Записи начнутся после первого выполненного шага.
